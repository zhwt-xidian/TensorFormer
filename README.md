# TensorFormer

TensorFormer: Spatial Structure-Preserving Tensor Modeling
for Remote Sensing Change Detection

## Overview

TensorFormer is a framework for bi-temporal remote sensing
image change detection. It includes tensor-based feature
modeling, a Condition-Aware Feed-Forward Network (CA-FFN),
and Cross-Scale Change Refinement (CSCR).

The framework is evaluated on the LEVIR-CD and WHU-CD datasets.

## Code Availability

The implementation has not yet been uploaded to this repository.
This repository currently contains a project description only.

## Datasets

This study uses the following publicly available datasets,
provided by their original authors:

- LEVIR-CD: https://justchenhao.github.io/LEVIR/
- WHU-CD: https://gpcv.whu.edu.cn/data/building_dataset.html

and citation requirements.
